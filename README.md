# Asistente Agroclimático para Café (Proyecto SI3003)

MVP de integración IA Clásica y LLMs para caficultores.

## Instrucciones de Ejecución
1. Instalar dependencias: `pip install -r requirements.txt`
2. Ejecutar la app: `streamlit run app.py`
3. Ingresa tu API Key en la barra lateral para probar el Agente.

# Declaración de uso de IA generativa

Se utilizó OpenAI Codex para interpretar la rúbrica, revisar el prototipo, escribir y verificar código del dashboard, CSP, indicador bayesiano, recuperación documental y ciclo de herramientas, y preparar documentación y casos de evaluación. Las fuentes técnicas se atribuyen en el corpus y el README identifica el origen de los datos meteorológicos.

La aplicación usa un modelo de OpenAI en el modo Agente LLM para elegir herramientas y redactar respuestas. El modo local consulta el corpus mediante TF-IDF y funciona sin credenciales. El equipo debe completar esta declaración con otros usos y aportes reales, y revisar y comprender los supuestos, el código y los resultados antes de entregar.
